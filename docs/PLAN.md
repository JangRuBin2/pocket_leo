# Pocket Leo 기획안 (v0.1)

> 상태: **컨펌 대기**. 맨 아래 "컨펌 필요 항목"만 답해주면 바로 개발 들어감.

## 1. 한 줄 정의

주머니 속에서 레오(포메라니안 + 스피츠 믹스)를 키우는 모바일 육성 게임.
실제 반려견을 키우면서 하는 일(밥, 산책, 배변 치우기, 간식, 목욕, 병원, 긁어주기, 놀이)을 짧고 찰진 터치 인터랙션으로 옮긴다.

- 플랫폼: 모바일 전용 (세로 화면 고정, 한 손 조작)
- 한 번 접속에 1~3분, 하루 여러 번 들어오는 구조
- 레오가 죽거나 가출하는 벌칙은 없음. 방치하면 삐지고 꼬질꼬질해질 뿐

## 2. 아트 디렉션

### 그림체
참고 일러스트(크레용 낙서 강아지)를 기준으로 한다.

- 크레용/색연필 질감의 삐뚤빼뚤한 외곽선, 안쪽은 결이 보이는 빗금 채색
- 따뜻한 종이색 배경, 그림자 없음, 원근 없음
- 프레임마다 선이 살짝 떨리는 "보일링(line boil)" 효과로 손그림 느낌 유지
- UI 글씨도 손글씨 계열

### 레오 캐릭터 시트 (사진 기준)
| 부위 | 특징 |
|---|---|
| 얼굴 | 동그란 곰돌이 컷, 진한 살구/오렌지색 |
| 가슴·몸 | 크림~흰색, 가슴털이 제일 풍성 |
| 꼬리 | 등 위로 말려 올라간 흰 솜뭉치 |
| 귀 | 작고 둥근 세모, 털에 반쯤 묻힘 |
| 눈 | 크고 까만 구슬 눈, 하이라이트 하나 |
| 코·입 | 까만 코, 주둥이 주변은 회색빛 흰 털, 웃으면 분홍 혀 |
| 다리 | 짧고 통통, 발끝은 크림색 |

### 표정/포즈 세트 (1차)
기본 서있기, 앉기, 활짝 웃기(혀 내밈), 졸린 눈(실눈), 혀 날름, 엎드려 자기, 삐짐(등 돌림), 꼬질꼬질, 젖은 털, 달리기, 꼬리 프로펠러.

## 3. 움직임 ("찰짐" 설계)

찰진 느낌은 전부 스프링 물리로 만든다. 키프레임 고정 애니메이션이 아니라 값이 튕기면서 따라오는 방식.

- **스쿼시 & 스트레치**: 점프·착지·먹기·쓰다듬기마다 몸이 눌렸다 늘어남
- **젤리 털**: 몸통이 움직이면 가슴털과 꼬리가 반 박자 늦게 출렁
- **숨쉬기**: 가만히 있어도 몸이 부풀었다 줄어듦, 눈 깜빡임, 귀 쫑긋
- **터치 반응**: 누른 자리가 꾹 들어갔다가 튕겨 나옴, 손가락을 눈으로 따라옴
- **햅틱**: 쓰다듬기·밥 먹기·똥 치우기에 짧은 진동 (지원 기기 한정)
- **파티클**: 하트, 물방울, 털 날림, 먼지를 크레용 낙서로

## 4. 게임 시스템

### 상태 수치 (6개)
| 수치 | 내려가는 조건 | 올리는 방법 |
|---|---|---|
| 배고픔 | 시간 경과 | 밥, 간식 |
| 기분 | 방치, 목욕·병원 직후 | 놀이, 긁어주기, 간식 |
| 청결 | 산책, 시간 경과, 안 치운 똥 | 목욕, 똥 치우기 |
| 체력 | 놀이, 산책 | 잠 |
| 건강 | 간식 과다, 청결·배고픔 장기 방치 | 병원, 꾸준한 관리 |
| 배변 욕구 | 식후 시간 경과 | 산책 중 배변 / 실내 배변 후 치우기 |

- 실제 시간 기준으로 흐름. 앱을 꺼도 계속 진행, 다시 켜면 그동안의 변화를 계산
- 밤(23시~7시)엔 레오가 자고 수치 감소가 느려짐
- 애정도(레벨): 돌볼수록 쌓이고, 새 장난감·간식·산책 코스·옷이 열림

### 돌봄 활동 (전부 미니 인터랙션)
| 활동 | 조작 | 포인트 |
|---|---|---|
| 밥 주기 | 사료 봉지를 기울여 그릇에 붓기 | 너무 많이 부으면 넘침, 레오가 발 동동 구르며 기다림 |
| 간식 주기 | 갈색 하트 모양 간식 "쌩쌩이" 들고 "앉아/손/기다려" 후 주기 | 기다려 성공 시 보너스, 많이 주면 건강 하락 |
| 산책 | 리드줄 잡고 옆으로 스크롤 | 냄새 맡기 구간, 다른 강아지 만남, 산책 중 배변 |
| 똥 치우기 | 봉투로 집어서 휴지통에 던지기 | 방치하면 청결 하락 + 파리 낙서 |
| 목욕 | 샤워기 → 문질러 거품 → 헹굼 → 드라이 | 싫어하는 표정, 드라이 때 털이 빵 터짐 |
| 병원 | 청진기·체온계·주사 대기 | 떨고 있는 레오 쓰다듬어 진정시키기 |
| 긁어주기 | 문지르기 | 부위별 반응 다름. 명당 찾으면 뒷다리 발차기 |
| 놀이 | 공 던지기, 터그(줄다리기), 숨바꼭질 | 공은 스와이프 방향·세기대로 날아감 |
| 재우기 | 불 끄고 이불 덮어주기 | 자는 동안 체력 회복 |

### 레오의 자율 행동
가만히 두면 알아서 돌아다니고, 하품하고, 장난감 물어오고, 배고프면 밥그릇 앞에 앉아 쳐다봄. 수치가 낮으면 말 대신 행동으로 티를 냄(UI 경고보다 행동이 먼저).

### 레벨과 이벤트 미니게임
- 활동을 하나 끝낼 때마다 경험치를 받음 (산책 25, 목욕·병원 20, 밥·공놀이·재우기 10, 쌩쌩이 8, 엄마 왔다 6, 응가 치우기 4, 명당 긁기 3)
- 다음 레벨까지 필요한 경험치: 150으로 고정
- 레벨이 오르면 이벤트 미니게임이 열림
- 미니게임 1: **레오 생일 케이크 만들기** (시트 3단 쌓기 → 크림 바르기 → 토핑 올리기 → 레터링 쓰기 → 초 켜기, 쌓기 정확도로 별 1~3개)
- 미니게임 2: **개인기 연습하기** (앉아: 쳐다볼 때만 2번 → 기다려: 연타로 5초 버티기 → 손: 발 든 순간 3번 연속 → 뽀뽀: 피해 다니는 주둥이에 4번, 전부 성공하면 왕큰 쌩쌩이)
- 미니게임 3: **양말 물기** (10초 안에 움직이는 양말 10개 이상 물기, 휴지를 물면 -1, 실패하면 재도전)
- 미니게임 4: **비오는 날** (번개가 번쩍한 뒤 천둥이 칠 때 레오 귀를 막아주기. 손 힘 게이지가 있어 계속 막고 있을 수는 없음. 8번 중 3번 놀라면 재도전)
- 레벨업 때 아직 안 열린 미니게임 중 하나가 랜덤으로 열림. 전부 열린 뒤에는 전체에서 랜덤, 직전에 나온 건 연속으로 안 나옴
- 한 번 플레이한 미니게임은 화면 위 '미니게임' 메뉴에서 다시하기 가능 (다시하기는 경험치 없음). 새 미니게임은 레벨업으로만 열림

### 부가 요소
- **레오 일기**: 하루 돌봄 기록이 그림일기 한 장으로 남음
- **도감/수집**: 장난감, 간식, 옷, 산책에서 주운 것들
- **알림**: "레오가 밥그릇 앞에서 기다려요" 같은 푸시 (2차)

## 5. 화면 구성

1. **집(메인)**: 거실에 레오. 상단에 수치 아이콘 6개, 하단에 활동 버튼 독
2. **활동 화면**: 활동마다 전용 화면(욕실, 산책길, 병원, 마당)
3. **가방**: 간식·장난감·옷 인벤토리
4. **일기장**: 날짜별 그림일기
5. **설정**: 소리, 진동, 알림

## 6. 사운드

전부 코드로 합성해서 만든다(외부 음원 없음, 저작권 이슈 없음).

- **BGM**: 느린 템포(70~85 BPM) 재즈 코드 진행(maj7, m9, 6/9)에 클래식풍 아르페지오와 멜로디. 음색은 펠트 피아노/로즈 일렉피아노 계열 + 부드러운 더블베이스 + 브러시 드럼
- **생성형**: 코드 진행 몇 벌 안에서 멜로디가 매번 조금씩 달라져서 반복 피로가 적음
- **상황별 변주**: 집(포근), 산책(경쾌), 목욕(통통 튀는 피치카토), 병원(살짝 긴장), 밤(자장가)
- **효과음**: 짖음·낑낑·헥헥은 합성음으로 귀엽게, UI는 실로폰/마림바 톤, 쓰다듬으면 음계가 올라감

## 7. 기술 스택 (제안)

| 항목 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | React + TypeScript + Vite | 익숙한 스택, 빠른 개발 |
| 렌더링 | Canvas 2D (자체 크레용 브러시) | 손그림 질감과 선 떨림을 코드로 그림, 이미지 에셋 불필요 |
| 애니메이션 | 자체 스프링 물리 | 찰진 움직임 직접 튜닝 |
| 사운드 | Web Audio API | BGM·효과음 전부 합성 |
| 저장 | IndexedDB (로컬) | 서버 없이 시작 |
| 앱 패키징 | PWA → Capacitor로 iOS/Android 빌드 | 한 코드로 웹 설치형과 스토어 앱 둘 다 |
| 배포 | GitHub Pages 또는 Vercel | 폰에서 바로 테스트 |
